## What are these?

Want to show your friends more info about the game you play - stuff like what kind of match are you in, what class you chose or how many in-game days have passed by? Well, then you're in luck! Because **Discord Rich Presences** was originally created for these exact situations.

Some games are able to extract extra info, but they decided we don't need to see it. That's where ___Discord Developer Portal___ Comes in hand. With a bit of coding and channeling to DC, you are now able to do what you wanted.

For lightweight use, I used ***python***. 

> Note: Because live reading can be hard (especially if the game exposes it in a weird way), there may be delays and sudden time skips, but don't mind them.

## What games are included?

1. Currently active games

  - Stardew Valley (Xbox version) - year, season, day, farm name

2. Planned games/features

## How to start them?
- Download and place the codes somewhere you will remember (if compressed, unzip them).
- Before running the .py files, make sure to install:
    * [Python](https://www.python.org/downloads/)
    * and run this in **cmd**: py -m pip install pypresence psutil
- After these, open a program that can run it (cmd, Powershell, Thonny, VSC, whatever your heart desires!)
  > Note: powershell, Command Prompt or Python IDLE are recommended for lightweight use
- Make sure you are in the right directory! (open folder/dir {link to your file's folder})
- Run the program (some offer a start button, elsewhere you have to type ___py {filename}.py___)
